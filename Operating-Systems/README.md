# Operating Systems Resources

This folder contains teaching materials, programming exercises, and demonstrations for Operating Systems.

## Topics

- Process scheduling algorithms
- Process synchronization
- Deadlocks
- Memory management
- Page replacement algorithms: FIFO, LRU, and Optimal
- Frame allocation and thrashing
- File system concepts

## Planned Practical Demonstrations

- Compare page faults across page replacement algorithms
- Simulate CPU scheduling and calculate waiting and turnaround times
- Demonstrate deadlock detection using sample resource-allocation data

Resources will be added progressively with explanations, sample inputs, outputs, and instructions for running each program.
