🏆 Key takeaway

    📘 How the algorithms work

    When memory frames are full, the operating system chooses a page to remove.

    FIFO

    First In, First Out removes the page that entered memory earliest. It is simple to implement with a queue.

    LRU

    Least Recently Used removes the page that has gone unused for the longest time in the past.

    Optimal

    Removes the page whose next use is farthest in the future, or that will never be used again. It is a theoretical benchmark because future references are not normally known.
