🏆 Key takeaway

    📘 How the algorithms work

    When memory frames are full, the operating system must choose a page to remove.

    FIFO — First In, First Out

    Removes the page that entered memory earliest, regardless of how recently it was used. It is simple to implement with a queue.

    LRU — Least Recently Used

    Removes the page that has not been used for the longest time in the past. It uses recent history to estimate future use.

    Optimal

    Removes the page whose next use is farthest in the future, or that will never be used again. It gives the minimum possible faults for a known reference string, but future knowledge makes it impractical in real systems.

    Tip: replacement is needed only when a fault occurs and all frames are full.
