    What is Belady's anomaly? For some reference strings, FIFO can produce more page faults when the number of frames increases. LRU and Optimal are stack algorithms, so their page-fault counts do not increase when additional frames are added.

    📘 How the algorithms work

    When memory frames are full, the operating system must choose a page to remove.

    FIFO — First In, First Out

    Removes the page that entered memory earliest, regardless of how recently it was used.

    LRU — Least Recently Used

    Removes the page that has not been used for the longest time in the past.

    Optimal

    Removes the page whose next use is farthest in the future, or that will never be used again. It is a benchmark because future references are not normally known.
